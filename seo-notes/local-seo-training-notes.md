## Reusable Local SEO Working Principles

- Think in service + location combinations.
- Prioritize lead intent over big national search volume.
- Build pages for real services and real service areas, not random keyword stuffing.
- Avoid cannibalization by assigning one primary keyword/intent to one page.
- For local business SEO, conversions matter: calls, forms, driving directions, and trust signals.

### Local keyword research sources / workflow

Observed framework for a local keyword:

Seed example: `dentist in Las Vegas`

Research sources/steps:

1. **Variations**
   - Generate wording variations around the service + city keyword.
   - Example variation shown: `Dentist Las Vegas`.
   - For local SEO, keyword order changes matter because users search naturally in multiple ways.

2. **Content**
   - Look at the content competitors have built around the keyword.
   - Extract headings, subtopics, FAQs, service details, proof/trust sections, and location signals.

3. **SERP**
   - Manually inspect Google results for the local keyword.
   - Identify ranking page types: homepage, service page, location page, listicle, directory, map pack, or review site.
   - Use SERP to understand search intent before deciding page type.

4. **Tools**
   - Use SEO tools such as SEMrush/Ahrefs/Keyword Planner/related keyword tools for volume, difficulty, and competitor ranking data.
   - For local SEO, low volume does not mean low value when the query has strong lead intent.

5. **Keyword gap analysis**
   - Compare the target site with competitors to find missing/weak keywords.
   - Use competitor keywords to expand service/location coverage.

### Keyword validation formula

Observed formula:

`Search volume + Search intent + SERP results`

Meaning:

- **Search volume**: check if the keyword has measurable demand, but for local SEO do not reject a keyword only because volume is small.
- **Search intent**: decide whether the query is informational, service/commercial, emergency/lead, comparison, or navigational.
- **SERP results**: verify what Google is actually ranking before creating the page.

Execution rule:

Do not create content only from tool volume. Confirm the SERP type and search intent first.

A Way to Freedom examples:

### Keyword distribution by page type

Observed page mapping notes:

- `Home` — separate keywords.
- `Service Pages` — separate keywords.
- `Location pages` — separate keywords.
- `Keywords cannibalism` warning.

Local SEO lesson:
- Do not put all local keywords on every page.
- Assign different keyword clusters to home, service pages, and location pages.
- Cannibalization happens when multiple pages target the same primary keyword/intent.

Recommended keyword distribution model:

1. **Homepage**
   - Broad brand + core service + main service region.
   - Example for A Way to Freedom:
     - Primary: `Delaware bail bonds`
     - Support: `24/7 bail bond help Delaware`, `licensed bail bond agent Delaware`.

2. **Service pages**
   - One service intent per page.
   - Examples:
     - `/services/felony` → `felony bail bonds Delaware`
     - `/services/misdemeanor` → `misdemeanor bail bonds Delaware`
     - `/services/secured` → `secured bail bonds Delaware`
     - `/services/surety` → `surety bonds Delaware`
     - `/services/payment` → `bail bond payment options Delaware`

3. **Location pages**
   - One location/city/county intent per page.
   - Examples:
     - `/wilmington-de-bail-bonds` → `Wilmington DE bail bonds`
     - `/newark-de-bail-bonds` → `Newark DE bail bonds`
     - `/new-castle-county-bail-bonds` → `New Castle County bail bonds`

4. **Blog/supporting content**
   - Informational questions and long-tail keywords.
   - Blogs internally link to the correct service/location page.
   - Blog should not compete with service page primary keywords.
